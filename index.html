▶ Открыть Вьетнам ТВ ⬇ Скачать приложение для Android (телефон, ТВ-приставка) ⬇ Скачать программу для Windows (все каналы, ~100 МБ)

Windows: распакуйте архив → откройте папку «Вьетнам ТВ» → запустите VietnamTV.exe. Если Windows скажет «неизвестный издатель» — «Подробнее» → «Выполнить в любом случае».

  1. Нажмите «Скачать приложение».
  2. Откройте скачанный файл vietnam-tv.apk.
  3. Если телефон спросит про «неизвестные источники» — разрешите установку для браузера.
  4. Нажмите «Установить» и откройте «Вьетнам ТВ».

В приложении работают все каналы. В браузере часть каналов может не открываться.
